The portfolio is not only a gallery of projects.

It is the main commercial platform for presenting:

web apps
landing pages

The portfolio should work as:

a platform that evolves over time

The first version does not need to be perfect.

The first version must be clear, strong, functional, bilingual, and ready to improve.

Language Strategy

The portfolio must be bilingual.

Required languages:

Spanish
English

Important rule:

Every visible text must have a complete English version and a complete Spanish version.

Do not leave mixed-language sections.

If the user switches to English, the full experience should feel professionally written in English.

If the user switches to Spanish, the full experience should feel natural and professional in Spanish.

Default language for first version:

Spanish can be the initial writing language
English must be implemented fully before publishing as an international-facing portfolio

Recommended structure:

/es
/en

Or a language toggle if the project architecture supports it cleanly.

English quality rule:

The English version must not feel like a literal translation.

It should sound professional, clear, and natural for international clients.

Spanish quality rule:

The Spanish version should be professional, clear, and natural, without sounding robotic.
