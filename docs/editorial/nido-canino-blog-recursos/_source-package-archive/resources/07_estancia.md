# Qué dejar listo para una estancia corta

## Información
- [ ] Contactos principales.
- [ ] Contacto alterno.
- [ ] Veterinario habitual.
- [ ] Alimentación.
- [ ] Medicación prescrita.
- [ ] Alergias/restricciones.
- [ ] Rutina de descanso.
- [ ] Antecedentes relevantes.

## Elementos
Confirme con Nido qué debe llevar. Evite empacar objetos innecesarios.

Según el caso puede requerirse:
- [ ] alimento;
- [ ] medicamento correctamente identificado;
- [ ] arnés/collar;
- [ ] instrucciones especiales;
- [ ] algún objeto aprobado por Nido si realmente ayuda a la rutina.

## Antes del ingreso
- [ ] La información sigue actualizada.
- [ ] No hubo enfermedad reciente sin informar.
- [ ] No hay un cambio nuevo de medicación sin informar.
- [ ] Los contactos estarán disponibles.

## Lo que no conviene
No envíe medicamentos sueltos sin identificación ni cambie dosis por conveniencia del viaje.
