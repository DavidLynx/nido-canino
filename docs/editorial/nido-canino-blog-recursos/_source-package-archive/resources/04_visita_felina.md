# Cómo preparar una visita felina a domicilio

## Antes de salir

- [ ] Deje alimento identificado y con cantidad/instrucciones claras.
- [ ] Confirme fuentes de agua y cómo se renuevan.
- [ ] Indique ubicación y rutina del arenero.
- [ ] Muestre dónde suele esconderse el gato.
- [ ] Deje transportadora accesible.
- [ ] Deje insumos de limpieza básicos.
- [ ] Informe puertas, ventanas o zonas que no deben abrirse.
- [ ] Informe si existen otros animales en casa.

## Rutina

- [ ] Horario aproximado de comida.
- [ ] Tipo de interacción habitual.
- [ ] Juegos o actividades que el gato disfruta.
- [ ] Cosas que conviene evitar.
- [ ] Conducta normal cuando llega una persona.

## Salud

- [ ] Medicación prescrita, si aplica.
- [ ] Instrucciones exactas del veterinario.
- [ ] Diagnósticos relevantes.
- [ ] Alergias.
- [ ] Veterinario habitual.
- [ ] Clínica de urgencia preferida si la familia tiene una.
- [ ] Autorización/contacto en caso de emergencia.

## Reporte que conviene recibir

- [ ] Gato visto/localizado.
- [ ] Comida.
- [ ] Agua.
- [ ] Arenero.
- [ ] Vómitos/diarrea visibles.
- [ ] Comportamiento.
- [ ] Medicación administrada, si corresponde.
- [ ] Incidentes.

---

> **Consejo:** deje instrucciones observables. “Come media taza” es más útil que “come poquito”.
