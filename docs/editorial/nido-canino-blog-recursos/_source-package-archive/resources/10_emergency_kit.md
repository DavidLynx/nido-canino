# Kit de emergencia para mascotas: lista base

Adapte esta lista a su mascota, hogar y recomendaciones veterinarias.

## Identificación y documentos
- [ ] Foto reciente.
- [ ] Datos del tutor.
- [ ] Contacto alterno.
- [ ] Información de microchip, si tiene.
- [ ] Copia de registros veterinarios relevantes.
- [ ] Prescripciones actuales.
- [ ] Información de propiedad/adopción si la considera necesaria.
- [ ] Instrucciones de cuidado.

## Alimentación y agua
- [ ] Reserva de alimento.
- [ ] Agua.
- [ ] Recipientes.
- [ ] Instrucciones de alimentación.
- [ ] Abrelatas manual si utiliza latas que lo requieran.

El CDC recomienda preparar una reserva amplia para emergencias; ajuste cantidades según espacio, clima, mascota y recomendaciones locales.

## Medicación
- [ ] Medicamentos prescritos.
- [ ] Instrucciones.
- [ ] Fechas de vencimiento revisadas.
- [ ] Información del veterinario.

## Transporte y control
- [ ] Collar con identificación.
- [ ] Correa.
- [ ] Arnés.
- [ ] Transportadora apropiada.
- [ ] Manta/toalla.
- [ ] Para gatos: elementos básicos de arenero si necesita evacuar.

## Limpieza y otros
- [ ] Bolsas.
- [ ] Toallas/papel.
- [ ] Elementos básicos de limpieza.
- [ ] Kit de primeros auxilios para mascotas recomendado por su veterinario.
- [ ] Objeto familiar pequeño si es útil y seguro.

## Plan
- [ ] Lugar al que podría evacuar con mascota.
- [ ] Persona de confianza si usted no está.
- [ ] Ruta de salida.
- [ ] Correa/transportadora accesible.
- [ ] Familia sabe quién se encarga de cada animal.

---

> **Guarde el kit donde pueda alcanzarlo.** Un kit perfecto escondido detrás de cajas sirve menos que uno sencillo y accesible.
