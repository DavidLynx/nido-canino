# Checklist para solicitar convivencia canina estructurada

Use esta lista antes de completar el Formulario PRO.

## Perfil general

- [ ] Nombre del perro.
- [ ] Edad aproximada.
- [ ] Sexo.
- [ ] Tamaño/peso aproximado.
- [ ] Esterilización, si aplica como dato relevante del formulario.

## Salud

- [ ] Condiciones médicas conocidas.
- [ ] Alergias.
- [ ] Medicamentos actuales.
- [ ] Limitaciones de movilidad.
- [ ] Indicaciones veterinarias relevantes.
- [ ] Contacto del veterinario habitual si el caso lo requiere.

## Rutina

- [ ] Horarios de alimentación.
- [ ] Tipo de alimentación.
- [ ] Horarios de paseo.
- [ ] Dónde y cómo suele descansar.
- [ ] Qué hace cuando queda solo.
- [ ] Señales o palabras que reconoce en casa.

## Convivencia

- [ ] Cómo responde a perros conocidos.
- [ ] Cómo responde a perros desconocidos.
- [ ] Estilo de juego si juega.
- [ ] Qué hace cuando quiere terminar una interacción.
- [ ] Reacción a personas nuevas.
- [ ] Antecedentes de peleas, mordidas, huidas o pánico, si existen.

## Manejo

- [ ] Uso de correa.
- [ ] Arnés/collar habitual.
- [ ] Transporte.
- [ ] Manipulación que tolera o evita.
- [ ] Qué suele ayudarlo a calmarse.

## Contexto reciente

- [ ] Cambios de vivienda.
- [ ] Enfermedades recientes.
- [ ] Cambios de familia.
- [ ] Viajes.
- [ ] Experiencias negativas recientes.
- [ ] Cambios de conducta.

---

> **No omita información por miedo a que “no lo reciban”.** La información real permite decidir mejor y preparar una experiencia más segura.

Complete el **Formulario PRO** con la información más precisa que tenga.
