# Checklist antes de una ausencia si su gato queda en casa

## Alimentación y agua
- [ ] Alimento suficiente.
- [ ] Porciones/instrucciones claras.
- [ ] Agua y recipientes disponibles.
- [ ] No hay cambio de dieta improvisado.

## Arenero
- [ ] Arena suficiente.
- [ ] Pala/bolsas.
- [ ] Ubicación sin cambios.
- [ ] Instrucciones de limpieza.

## Seguridad
- [ ] Ventanas seguras.
- [ ] Balcones seguros.
- [ ] Puertas identificadas.
- [ ] Plantas/objetos peligrosos fuera de alcance.
- [ ] Transportadora accesible.

## Rutina
- [ ] Horarios aproximados.
- [ ] Lugares de escondite conocidos.
- [ ] Juego/interacción habitual.
- [ ] Conductas que serían inusuales.

## Salud
- [ ] Medicación, si aplica.
- [ ] Instrucciones veterinarias.
- [ ] Contacto del veterinario.
- [ ] Contacto de emergencia familiar.
- [ ] Autorización clara para una urgencia.

## Persona cuidadora
- [ ] Tiene llaves/acceso.
- [ ] Sabe dónde encontrar al gato.
- [ ] Sabe dónde está el kit.
- [ ] Puede contactarlo.
- [ ] Tiene un plan si usted no responde.

---

### Antes de cerrar la puerta
Haga una última revisión de agua, alimento, arenero, ventanas y transportadora.
